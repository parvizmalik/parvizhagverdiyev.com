*This is a sample post that shows how interviews are formatted. Delete `src/content/posts/sample-interview.md` when you no longer need it.*

Start with a short introduction: who the guest is, why you spoke with them, and when and where the conversation happened. Set the `guest:` field in the front matter, and the guest's name will appear under the title and in the post list.

**Parviz:** Start each turn with the speaker's name in bold, followed by a colon. The name is set in a small sans-serif face so the transcript is easy to scan.

**Guest:** And the reply goes in its own paragraph. Long answers can run for several paragraphs.
